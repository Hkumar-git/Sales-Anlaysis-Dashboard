📊 Sales Analysis Dashboard

This project focuses on analyzing sales data using Excel, SQL, and Power BI to derive meaningful business insights and build an interactive dashboard.

Tools Used

- Microsoft Excel
- SQL
- Power BI

---

Excel (Data Preparation & Analysis)

- Cleaned and structured raw dataset
- Created Pivot Tables for:
  - Sales by Category
  - Profit by Region
- Used formulas like SUM, AVERAGE, COUNTIF
- Built initial dashboard with slicers

---

SQL (Data Analysis)

- Created table and inserted sample data
- Used SQL queries for analysis:
  - Total Sales
  - Sales by Category
  - Profit by Region
  - Top Performing Category
- Applied GROUP BY, SUM, and ORDER BY

---

Power BI (Visualization)

- Built interactive dashboard
- Created charts:
  - Sales by Category
  - Profit by Region
- Added KPI cards:
  - Total Sales
  - Total Profit
  - Total Orders
- Implemented slicers for dynamic filtering
